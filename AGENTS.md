# AGENTS.md

## Главные правила работы с проектом

Ты работаешь в проекте marketplace-ai. Действуй как аккуратный помощник-разработчик.

Перед изменениями:

1. Сначала кратко объясни план.
2. Делай минимальные изменения.
3. Не выполняй крупные рефакторинги без подтверждения.
4. Не добавляй новые зависимости без разрешения.
5. После изменений проверь код, если есть доступные команды тестов/линта.

---

Никогда не выполнять команды, которые могут удалить данные или схему БД:

- prisma migrate reset
- prisma db push --force-reset
- DROP TABLE
- DROP DATABASE
- TRUNCATE
- DELETE без WHERE
- ALTER TABLE DROP COLUMN
- npx prisma db push --accept-data-loss

Перед любыми миграциями сначала показать план изменений и дождаться подтверждения пользователя.
